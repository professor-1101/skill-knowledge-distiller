# formalize (R3) — claims become canonical rules

Role: formalizer. Source access: **no**.

State each consolidated claim as `WHEN / THEN / BECAUSE`, lifted out of the
source's own framing.

**The elevation target is precise: the most general statement that still names
a specific condition and a specific consequence.** Below it, the rule is only
usable by someone who read the same example. Above it, you have a platitude —
which passes every gate and changes no decision.

`BECAUSE` states the **mechanism**, not a restatement of `THEN` and not an
action. A reader who understands why a rule holds can handle the case it does
not mention; a reader given an order cannot.

`name` is a short imperative. Never a truncation of the statement — a
mechanically cut name reads as a rule and is not one.

A claim that cannot be stated this way is dispositioned `not-transferable` or
`platitude`, with a reason. Forcing it produces something worse than losing it.
